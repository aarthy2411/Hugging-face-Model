
# Hugging Face Model Chatbot

A simple AI chatbot built using Streamlit, Hugging Face Inference API, and the OpenAI GPT-OSS 120B model.

## Project Overview

This project demonstrates how to build an interactive chatbot using a Hugging Face API token.

The application provides a simple chat interface where users can enter their questions and receive responses generated by the GPT-OSS 120B model.

The chatbot is developed using Python and Streamlit, with the Hugging Face router used to access the model.

## Features

- Interactive chatbot interface
- Hugging Face API token authentication
- GPT-OSS 120B model integration
- Maintains conversation history during the session
- Password-protected API token input
- Simple and user-friendly Streamlit interface

## Technologies Used

- Python
- Streamlit
- OpenAI Python SDK
- Hugging Face Inference API
- GPT-OSS 120B

How It Works

The application uses Streamlit to create the chatbot interface.
The user enters their Hugging Face API token through the application. The token is then used to create an OpenAI-compatible client connected to the Hugging Face router.
The chatbot sends the user's messages to the GPT-OSS 120B model and displays the generated response in the Streamlit interface.
The conversation history is stored using Streamlit session state so that previous messages remain available during the session.<img width="1067" height="820" alt="Output" src="https://github.com/user-attachments/assets/46cb6aec-055e-444c-a686-d2484e7c7143" />
